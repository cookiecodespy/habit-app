# CHANGELOG-RULE.md

## Regla general de continuidad

Cada vez que se meta mano a cualquier archivo del repo (por humano o IA), se debe dejar **además** un archivo Markdown con fecha y hora del cambio para que cualquier agente sin contexto pueda ubicarse rápido.

## Formato obligatorio

- Ubicación recomendada: `docs/session/`
- Nombre de archivo: `YYYY-MM-DD-HHMM.md`
- Ejemplo: `2026-04-23-0248.md`

## Qué debe incluir

1. Qué se cambió
2. Por qué se cambió
3. Qué archivos se tocaron
4. Estado actual después del cambio
5. Qué falta o qué riesgos quedan
6. Cómo retomar desde ahí sin perder tiempo

## Regla operativa

No dar un cambio por cerrado sin dejar su nota `.md` correspondiente.

Esto aplica a este repo y debería tratarse como convención permanente.
