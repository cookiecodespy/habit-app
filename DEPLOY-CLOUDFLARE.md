# Deploy privado recomendado

## Opción recomendada
Cloudflare Pages + Cloudflare Access

## Flujo
1. Subir este proyecto a GitHub.
2. Conectar el repo en Cloudflare Pages.
3. Build command: vacío
4. Output directory: /
5. Activar Cloudflare Access para restringir acceso solo a tu correo.

## Uso en teléfono
1. Abrir la URL protegida.
2. Iniciar sesión.
3. Agregar a pantalla de inicio.
