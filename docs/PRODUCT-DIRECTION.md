# Product Direction - Boss Mode

Fecha: 2026-04-22

## Decisión de enfoque
La app debe simplificarse. La dirección correcta no es una gamificación cargada, sino una herramienta diaria más sobria, premium, minimalista y realmente útil.

## Qué sí queremos
- Estética dark premium, tipo iPhone / app bien diseñada
- Sensación de producto serio, no demo improvisada
- Uso diario real
- Menos ruido, más claridad
- Progreso visual elegante
- Mejor jerarquía visual
- Quick capture útil
- Hábitos con visualización tipo heatmap / consistency grid
- Objetivos / metas importantes con progreso simple
- Tareas limpias y bien organizadas

## Referencias visuales y funcionales
Inspiraciones compartidas por Boss:
1. Hábitos con grilla/heatmap visual
2. Tasks/backlog limpio y ordenado
3. Goals con tarjetas sobrias y progreso
4. Mood/check-in como idea secundaria, no protagonista
5. Dashboard premium, silencioso, elegante

## Estructura objetivo actual
Reducir la app a 3 áreas principales:

### 1. Hoy
- tareas del día
- quick add
- resumen claro
- progreso diario

### 2. Hábitos
- lista limpia
- rachas
- heatmap / consistency grid

### 3. Objetivos
- metas activas
- progreso manual simple
- tarjetas sobrias

## Qué sacar o bajar de prioridad
Estas ideas pasan a cola / backlog, no son prioridad ahora:
- premios
- liga
- XP
- nivel
- social
- versus
- rivals (Karina, Nico, etc.)
- leaderboard
- exceso de bloques explicativos
- features futuras que no aportan uso diario inmediato

## Criterios de diseño
- dark navy / graphite
- glass muy sutil o incluso menos glass
- cards sobrias
- tipografía limpia
- spacing premium
- menos elementos gritones
- menos “juego”, más “life OS”

## Criterios de producto
Cada pantalla debe responder al menos una de estas preguntas:
- ¿Qué necesito hacer hoy?
- ¿Qué hábito importante estoy sosteniendo?
- ¿Cómo va una meta importante?

Si algo no ayuda a eso, probablemente sobra por ahora.

## Regla de priorización
Ideas nuevas o features futuras que aparezcan:
- no meterlas al tiro
- dejarlas en cola
- priorizar foco, claridad y utilidad diaria
